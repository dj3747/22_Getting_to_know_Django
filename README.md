# 22_Getting_to_know_Django

## Проект интернет-магазина

## Установка:
1. Клонируйте репозиторий `git@github.com:dj3747/22_Getting_to_know_Django.git`
2. Инициализируйте `poetry init` и установите зависимости после обновления `pyproject.toml` командой `poetry install`
3. Создайте файл `.gitignore`
4. Подключили СУБД `PostgreSOL` для работы в проекте

## Структура проекта
Проект состоит из следующих пакетов и приложений:

1.`config` - пакет с базовыми настройками
2.`catalog` - приложение, созданное на основе паттерна `MTV` c помощью
фреймворка `Django`. Для стилизации страниц используется `Bootstrap`
3.В приложении `catalog` созданы модели `Category` и `Product`

Перенесли отображение моделей в базу данных с помощью инструмента миграций. Создали суперпользователя.
Воспользовались инструментом `shell` для выполнения запросов.
Сформировали фикстуры для моделей `Category` и `Product`.
Создали кастомную команду для добавления тестовых продуктов.
Реализован новый контроллер и шаблон для отображения страницы с подробной информацией о товаре.
Выделен общий (базовый) шаблон.
Все контроллеры приложения catalog переведены в `CBV`.
Создано приложение блога.
Для блоговой записи реализован полный `CRUD`.
При открытии отдельной статьи увеличивается счетчик просмотров статьи.
